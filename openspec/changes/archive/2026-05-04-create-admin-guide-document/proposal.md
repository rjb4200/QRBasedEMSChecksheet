## Why

New administrators need comprehensive documentation explaining how to manage the EMS Checksheet system. Currently, there is no formal admin guide covering the admin panel pages, system functionality, and common tasks. A detailed ADMINGUIDE.md will reduce training time, prevent configuration errors, and ensure consistent administration practices.

## What Changes

- Create ADMINGUIDE.md document in the project root
- Document all admin panel pages with detailed explanations
- Include Do's and Don'ts for system administration
- Provide dedicated sections for common administrative tasks:
  - Adding new equipment to the catalog
  - Creating new units
  - Building compartments with equipment
  - Linking compartments for synchronized configuration
  - Printing daily checksheets and records
- Explain all system features including: units management, fleet overview, checksheet management, user management, export/import, archive/OOS features

## Capabilities

### New Capabilities

- `admin-documentation`: Comprehensive admin guide documenting the admin panel, system functionality, and common tasks.

### Modified Capabilities

- None. This is a documentation artifact that doesn't change system functionality.

## Impact

- New ADMINGUIDE.md file in project root
- No code changes required
- Benefits onboarding of new administrators
