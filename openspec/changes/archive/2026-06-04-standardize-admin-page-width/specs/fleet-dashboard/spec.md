## ADDED Requirements

### Requirement: Admin pages use consistent max-width
The admin pages SHALL use `max-w-7xl` as the standard container width for content sections.

#### Scenario: Archives page matches Fleet Panel width
- **WHEN** the archives page renders
- **THEN** the content section SHALL use `max-w-7xl`

#### Scenario: Equipment catalog matches Fleet Panel width
- **WHEN** the equipment catalog page renders
- **THEN** the content section SHALL use `max-w-7xl`
