## ADDED Requirements

### Requirement: Kit assignment management is available on the Kits page
Kit-to-unit assignments SHALL be manageable from the Admin Kits page using an edit-mode toggle, without changing existing unit-side assignment behavior.

#### Scenario: Kits page edit mode available
- **WHEN** an admin views a kit card on the Kits page
- **THEN** the assigned units section SHALL include an edit-mode toggle
- **AND** read-only display SHALL remain the default view
