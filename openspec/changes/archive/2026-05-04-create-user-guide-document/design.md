## Context

The system is used by EMS crew members to perform daily equipment checkoffs on vehicles. New employees need to understand how to access the system, complete their checkoffs correctly, and follow proper procedures. The user guide will serve as the primary reference document for onboarding.

## Goals / Non-Goals

**Goals:**
- Create comprehensive user guide for new employees
- Document step-by-step checkoff workflow
- Define clear do's and don'ts
- Include troubleshooting section
- Explain exception handling and reporting

**Non-Goals:**
- Admin functionality documentation (separate admin guide)
- Technical system architecture details
- Troubleshooting for system administrators

## Decisions

### 1. Document Structure

**Decision:** Structure the user guide with these main sections:
1. Introduction - What is the EMS Checksheet system
2. Getting Started - How to access the system
3. Daily Checkoff Workflow - Step-by-step process
4. Understanding Exceptions - What are exceptions and how to handle
5. Do's and Don'ts - Rules and best practices
6. FAQ - Common questions and answers

**Rationale:** This structure follows natural learning progression - from understanding what the system is, to how to use it, to best practices and troubleshooting.

### 2. Content Level

**Decision:** Write at a level appropriate for field crew members - clear, concise, practical language without technical jargon.

**Rationale:** Users are EMS professionals, not IT specialists. The guide should be easy to read during busy shifts.

### 3. Visual Aids

**Decision:** Include simple workflow diagrams and screenshots where helpful to illustrate key steps.

**Rationale:** Visual learners benefit from seeing the actual interface. Keep diagrams simple and focused.

## Risks / Trade-outs

- **Outdated Information:** System updates may make guide outdated. Mitigated by keeping guide in version control and updating with each major change.
- **Too Long:** Users may not read a lengthy document. Mitigated by keeping sections concise and using headers for scanning.
