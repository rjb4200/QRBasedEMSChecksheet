## ADDED Requirements

### Requirement: Introduction Section
The user guide SHALL include an introduction explaining what the EMS Checksheet system is and its purpose.

#### Scenario: Introduction provides context
- **WHEN** a new employee reads the introduction
- **THEN** they SHALL understand what the system does and why it's used

### Requirement: Getting Started Section
The user guide SHALL explain how to access the system and navigate to the units page.

#### Scenario: Access instructions provided
- **WHEN** a new employee reads getting started
- **THEN** they SHALL know how to access the checkoff system
- **AND** they SHALL know how to find their unit

### Requirement: Daily Checkoff Workflow
The user guide SHALL document the step-by-step process for completing a daily checkoff.

#### Scenario: Workflow steps documented
- **WHEN** a new employee follows the guide
- **THEN** they SHALL be able to complete a full checkoff from start to finish
- **AND** the steps SHALL include scanning QR code, checking items, handling exceptions, and saving

### Requirement: Understanding Exceptions
The user guide SHALL explain what exceptions are and how to handle items below par.

#### Scenario: Exception handling explained
- **WHEN** a new employee encounters an exception
- **THEN** they SHALL know what it means
- **AND** they SHALL know how to properly document it

### Requirement: Do's and Don'ts Section
The user guide SHALL clearly list allowed and prohibited actions when using the system.

#### Scenario: Rules clearly stated
- **WHEN** a new employee reads the do's and don'ts
- **THEN** they SHALL know what is expected of them
- **AND** they SHALL know what behaviors to avoid

### Requirement: FAQ Section
The user guide SHALL include answers to frequently asked questions.

#### Scenario: Common questions answered
- **WHEN** a new employee has a question
- **THEN** they SHALL be able to find answers in the FAQ section

### Requirement: Crew Names and Locking
The user guide SHALL explain how to enter crew names and lock the checkoff.

#### Scenario: Crew name workflow documented
- **WHEN** a new employee needs to enter crew names
- **THEN** they SHALL know how to do so
- **AND** they SHALL understand the importance of locking the checkoff

### Requirement: Comments Section
The user guide SHALL explain how to add comments for supervisors.

#### Scenario: Comments feature documented
- **WHEN** a new employee needs to communicate with supervisors
- **THEN** they SHALL know how to add comments
- **AND** they SHALL know when comments are appropriate
