## Why

New employees need clear guidance on how to use the EMS Checksheet system for daily unit checkoffs. Currently, there is no formal documentation explaining the workflow, expectations, or best practices. A comprehensive user guide will reduce training time, prevent errors, and ensure consistent checkoff procedures across all crew members.

## What Changes

- Create USERGUIDE.md document in the project root
- Document the complete checkoff workflow from scanning QR code to completing checkoff
- Explain do's and don'ts for using the system
- Include section on how to handle exceptions and report issues
- Document crew roles and responsibilities during checkoff
- Include FAQ section for common questions

## Capabilities

### New Capabilities

- `user-documentation`: Comprehensive user guide documenting the checkoff workflow and system usage for new employees.

### Modified Capabilities

- None. This is a documentation artifact that doesn't change system functionality.

## Impact

- New USERGUIDE.md file in project root
- No code changes required
- Benefits onboarding of new crew members
