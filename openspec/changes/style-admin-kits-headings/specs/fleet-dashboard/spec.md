## MODIFIED Requirements

### Requirement: Admin kits page uses consistent heading styling
The admin kits page SHALL use "Shared Layouts" as the large black page title and display "Create Kit" and "Create Kit From Compartment" subheadings in red text, consistent with the heading pattern used by the Fleet Panel and Units pages.

#### Scenario: Page title is Shared Layouts
- **WHEN** the admin kits page renders
- **THEN** "Shared Layouts" SHALL appear as the large black H1 page title

#### Scenario: Create headings use red text
- **WHEN** the admin kits page renders
- **THEN** "Create Kit" and "Create Kit From Compartment" subheadings SHALL use red text styling
