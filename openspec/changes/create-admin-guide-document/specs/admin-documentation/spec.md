## ADDED Requirements

### Requirement: Admin Panel Pages Documentation
The admin guide SHALL document all pages in the admin panel with detailed explanations.

#### Scenario: All pages documented
- **WHEN** an admin reads the guide
- **THEN** they SHALL find documentation for Fleet, Units, Checksheets, Equipment Catalog, and User Management pages

### Requirement: Do's and Don'ts Section
The admin guide SHALL clearly list allowed and prohibited actions for system administration.

#### Scenario: Rules clearly stated
- **WHEN** a new admin reads the do's and don'ts
- **THEN** they SHALL know what is expected of them
- **AND** they SHALL know what behaviors to avoid

### Requirement: Adding Equipment Task Guide
The admin guide SHALL include a dedicated section explaining how to add new equipment to the catalog.

#### Scenario: Equipment addition documented
- **WHEN** an admin needs to add new equipment
- **THEN** they SHALL find step-by-step instructions in the guide

### Requirement: Common Tasks Coverage
The admin guide SHALL cover all common administrative tasks beyond the specifically listed ones.

#### Scenario: Comprehensive task coverage

- **THEN** they SHALL find guidance for that task in the guide
